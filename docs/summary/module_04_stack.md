# Module 04 Summary: Stack

This document outlines the core theoretical mechanics, grammar parsing principles, and invariants underlying Module 04.

---

## 1. The Stack Abstract Data Type & LIFO Discipline

A **Stack** is a linear data structure operating under the **Last-In, First-Out (LIFO)** policy:
* Elements are inserted via `push` and removed via `pop` strictly from the same boundary (the *top* of the stack).
* In dynamic memory arrays (such as Python's `list`), appending to the tail and popping from the tail run in amortized $\mathcal{O}(1)$ time with optimal sequential cache locality.

---

## 2. Theoretical Invariant: Context-Free Language & Dyck Paths

The balanced parentheses problem is mathematically modeled as membership in the **Dyck Language** $\mathcal{D}$, a classical context-free language generated by the production grammar:
$$S \to \varepsilon \mid (S) \mid [S] \mid \{S\} \mid SS$$

### The Invariant of Well-Nested Prefixes
For any balanced bracket string $w = c_1 c_2 \dots c_n$:
1. **Prefix Non-Negativity**: For any prefix $w[1 \dots k]$, the count of closing delimiters of any type can never exceed the count of opening delimiters of that same type.
2. **Immediate Matching (LIFO Alignment)**: If $c_k$ is a closing delimiter, its matching open delimiter must be the *most recent unclosed* open delimiter in the prefix $w[1 \dots k-1]$.
3. **Empty Termination**: Upon reading the final symbol $c_n$, the count of open delimiters must be exactly equal to the count of closing delimiters, meaning zero unclosed frames remain on the stack.

---

## 3. Algorithmic State Machine

* **State**: Current stack $S = [s_0, s_1, \dots, s_{m-1}]$ where $s_{m-1}$ is the top.
* **Transition**:
  * If input symbol $c \in \Sigma_{\text{open}}$:
    $$S \leftarrow S \cup \{c\}$$
  * If input symbol $c \in \Sigma_{\text{close}}$:
    * If $|S| = 0 \implies$ Reject immediately (closing delimiter without opener).
    * If $s_{m-1} \ne \text{match}(c) \implies$ Reject immediately (mismatched grammar type).
    * Else $S \leftarrow S \setminus \{s_{m-1}\}$ (successful reduction).
* **Final Acceptance**: Accept if and only if $|S| = 0$.
